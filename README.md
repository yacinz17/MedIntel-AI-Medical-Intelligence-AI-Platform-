# MedIntel AI 🩺🤖

MedIntel AI is an AI-powered medical platform that analyzes patient data, processes X-ray images for chest disease detection, and understands medical text.  
Built with **Machine Learning**, **Deep Learning**, and **Natural Language Processing**, it’s deployed via **FastAPI** and **Streamlit** for quick, accessible healthcare insights.

## 🚀 Features
- 📊 **Patient Data Analysis** – Predict health outcomes from structured data.
- 🩻 **X-ray Image Diagnosis** – Detect chest diseases using deep learning.
- 📝 **Medical Text Understanding** – NLP model for medical document insights.
- 🌐 **FastAPI Backend** – High-performance API for AI models.
- 🎨 **Streamlit Frontend** – Interactive web interface for easy use.

## 🛠️ Tech Stack
- **Languages:** Python
- **Frameworks:** FastAPI, Streamlit
- **AI Libraries:** TensorFlow, PyTorch, Scikit-learn
- **NLP:** Transformers, SpaCy
- **Deployment:** Ngrok, Localhost
